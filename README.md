# CardTalk

面向口语有限的儿童与家庭，以及卒中后有沟通困难的成人与家庭的中文 AAC 辅助沟通产品。

核心流程：创建聊天室 → 分类选卡 → 联网 AI 扩写 → 本人确认候选 → 发声 → 保存记录与反馈 → 结束聊天室。

- 单次表达最多 20 张卡片，AI 最多提供 3 个候选。
- 移动端覆盖 Android、iOS、HarmonyOS NEXT 手机和平板；电脑使用 Web。
- 微信小程序作为本机保存的体验入口，联网时限额体验 AI，断网时使用已准备的基础沟通能力。
- 使用人管理、场景管理和分析为可独立开启的付费能力；其他收费范围待确认。
