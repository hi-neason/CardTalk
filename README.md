# CardTalk

面向口语有限的儿童与家庭，以及卒中后有沟通困难的成人与家庭的中文 AAC 辅助沟通产品。

当前版本已实现沟通、家庭管理、个人适配、分析报告，以及可配置的家庭账户、独立权益、显式云同步、公共资源和运营支持。基础沟通包含创建/恢复/结束同机聊天室、分类搜索选卡、联网 AI 扩写、候选确认与修改、声音播放、本机历史及理解反馈。单次表达最多 20 张卡片，最多 3 个候选；AI 不会自动确认或发声。

## 在 MacBook 本机运行

需要 Node.js 22+（附带 npm 10+）、JDK 21+、Maven 3.6.3+。开发时无需 Docker、数据库或云部署。

```sh
npm ci
cp backend/.env.example backend/.env
```

在本机编辑 `backend/.env`，填入 `CARDTALK_LLM_API_KEY`。首期供应商为 DeepSeek，模型名称可通过 `CARDTALK_LLM_MODEL` 配置。密钥只放在后端；未配置时仍可选卡、展示原始表达、播放固定卡片声音和查看本机记录，扩写会明确提示服务未配置。

打开两个终端，在仓库根目录分别运行：

```sh
npm run dev:backend
```

```sh
npm run dev
```

访问 **http://127.0.0.1:5173**。H5 开发服务器把 `/api` 代理给本机后端 8080。启动脚本自动读取 `backend/.env`，不执行文件中的代码、不展开变量；外部环境变量优先。前后端默认仅监听本机。若修改后端端口，需要同步修改 `frontend/vite.config.ts` 的代理。

设置中提供三个独立、保存在本机的开关：

- **AI 扩写**：开启后用 DeepSeek 整理选卡；关闭后直接使用原始表达。
- **语音合成**：开启后用科大讯飞拟人合成；关闭后用设备发声。Web 中文声音依赖系统/浏览器；小程序不能直接调用系统朗读新句子，保留固定卡片声音和文字展示。
- **情绪识别**：根据明确选中的开心、难过、生气、害怕卡片传递语气。无情绪、冲突、否定或修改过的表达使用自然语气，不猜测本人情绪。

默认开启扩写，关闭讯飞合成与情绪识别。三个开关互相独立；关闭扩写仍可合成已确认的原始表达。切换开关会取消相关等待/播放，扩写或情绪设置变化会清除待确认候选，保留原始选卡与已确认历史。

讯飞凭据在 `backend/.env` 配置 `CARDTALK_XFYUN_APP_ID`、`CARDTALK_XFYUN_API_KEY`、`CARDTALK_XFYUN_API_SECRET`；`CARDTALK_XFYUN_VCN` 必须使用账号已开通的超拟人音色。普通超拟人接口未提供这里所需的显式四情绪参数。情绪合成使用官方多风格协议，需要设置 `CARDTALK_XFYUN_ENGINE=voice-clone` 并填写已授权多风格资源的 `CARDTALK_XFYUN_RESOURCE_ID`。只消费已有资源，本应用不采集录音或训练音色。设置页展示配置状态；不支持情绪的音色会明确提示，不模拟情绪合成。

DeepSeek 与讯飞分别开通和配置；修改后端环境文件后重新启动 `npm run dev:backend`。接口和授权边界见 [后端文档](backend/API.md)。

## 微信小程序与其他平台

```sh
npm run build:weixin
```

使用微信开发者工具导入 `frontend/dist/build/mp-weixin`，配置自己的 AppID。连接后端时在 `frontend/.env.local` 设置 `VITE_API_BASE_URL` 为可达的 HTTPS 地址，重新构建，并在微信后台设置 request 合法域名。本机测试可用开发者工具的域名检查设置；正式发布仍需 HTTPS 与合法域名配置。

小程序将沟通数据保存在本机，联网时限额体验扩写。固定卡片声音在资源已下载并保留时可离线使用；新句子需要启用已配置的讯飞语音。H5 生产构建已提供 Service Worker：完成联网安装并准备资源后可断网刷新和使用基础表达；首次离线访问或缓存被清除时不可用。API 不缓存成伪成功，断网不扩写。

采用传统 uni-app + Vue 3 + TypeScript，H5、mp-weixin、Android、iOS、HarmonyOS NEXT 五端资源构建通过。移动端已接入系统 TTS、音频、图片、文件备份、内存登录和管理入口；平台原生编译、签名包、手机/平板真机验收尚未完成，详见 [移动端说明](docs/MOBILE.md)。电脑使用 Web；微信体验版不开放高级管理入口。

## 家庭管理与功能授权

Web 顶栏「家庭管理」提供：多使用人资料、自定义卡片、场景的新增/编辑/归档/恢复。支持兴趣、性格、表达习惯、带记录人与日期的家人观察；卡片支持分类、词语/整句、内置图案和本机照片；场景支持活动/物品描述与推荐卡片。使用人与场景均支持本机图片上传、预览、替换和移除，并在聊天室及历史中展示。

在创建聊天室时选择使用人和场景，并可单独填写本次状态。沟通固定当时的资料快照，后续编辑或归档不会改写当前会话和历史。扩写只发送相关资料与卡片文字，不发送照片或长期观察。设备试听不调用付费语音；照片与家庭资料保存在当前浏览器，并随本机备份导出。

未选择正式家庭时，本机体验通过四个独立的**开发开关**控制，在 `backend/.env` 配置并重启后端：

```dotenv
CARDTALK_PROFILE_MANAGEMENT_ENABLED=true
CARDTALK_SCENARIO_MANAGEMENT_ENABLED=true
CARDTALK_CUSTOM_CARDS_ENABLED=true
CARDTALK_ANALYTICS_ENABLED=true
```

示例默认档案/场景关闭、自定义卡片开启；功能关闭时现有资料只读，基础沟通与历史保留。登录后需明确选择「使用这个家庭的功能」，按服务端家庭角色与独立权益授权，不与体验开关合并。已实现订单、试用/期限、续期、取消和退款流程；默认支付服务关闭且商品目录为空。微信 H5 支付适配已有契约测试，实际商户支付尚未验收，原生端目前仅管理权益和订单。详见 [家庭管理](docs/FAMILY.md) 与 [商业授权](docs/BILLING.md)。

「分析报告」支持按人、场景、日期、来源与状态筛选、前期对比、过程指标、统计依据、保存/重新生成和范围导出。可选 AI 说明只接收匿名汇总整数，采用后才保存；已保存报告在权益不可用时仍可查看和导出。详见 [分析说明](docs/ANALYTICS.md)。

设置支持本机 JSON 备份导入：预览后确认替换，失败保留当前数据，未结束沟通需先结束。备份与统计报告用途不同，统计报告不能恢复数据。

## 验证

```sh
npm test
npm run typecheck
npm run test:backend
npm run build
npm run build:weixin
```

浏览器回归使用系统 Chrome；先启动上面的前后端，再运行：

```sh
npm run test:e2e
```

浏览器测试中的候选由明确的测试 fixture 提供；后端测试使用本机 HTTP/WebSocket 测试服务，不消耗真实 DeepSeek/TTS 额度。另有浏览器用例验证真实本机后端未配置时的错误和原始表达回退。详细证据及边界见 [MVP 交付说明](docs/MVP.md)。

## 数据与技术文档

沟通记录保存在当前浏览器/微信本机存储，刷新可恢复；清理客户端数据会移除记录，请通过设置导出备份。联网扩写会向后端和供应商发送本次选卡及必要场景/参与者上下文。匿名扩写服务只保存额度与去重元数据，不保存沟通正文；用户显式选择云同步后，后端会保存所选家庭资料和记录，照片与观察另行授权。登录、购买或开启分析均不会自动上传本机历史。这不代表供应商不留存数据。

后端保留单进程 JSON 开发模式，并提供 PostgreSQL 事务、迁移、持久扩写/报告额度、对象存储、家庭权限与同步。Docker/Caddy/PostgreSQL 部署配置及隔离备份恢复脚本已交付；真实隔离 PostgreSQL 与文件资产恢复通过。完整镜像构建受镜像仓库网络限制，公网 HTTPS 和正式基础设施尚未验收。详见 [部署说明](deploy/README.md) 和 [长任务检查点](docs/LONG_TASK.md)。
