# 本机家庭管理第一阶段

日期：2026-10-12。对应产品全景 M02、M04、M06、M07、M10 的本机闭环；正式家庭账户、跨设备同步和移动原生验收尚未交付。

## 使用流程

1. Web 顶栏进入「家庭管理」，创建使用人、卡片和场景。
2. 使用人可填写年龄、语言、兴趣、性格与表达习惯；家人观察记录有独立来源和日期。
3. 自定义卡片可以是词语或整句，选择分类、内置图案或本机图片，并关联场景。
4. 场景可说明环境、常见活动和物品，选取推荐卡片；通用词汇始终可选。
5. 创建聊天室选择使用人和场景，单独填写当次状态。选卡后扩写、确认、朗读和反馈延续原沟通流程。
6. 本机历史按使用人档案、预设、场景和文字查看；档案与资源可归档、恢复。

当前会话及历史使用创建时的资料和选卡快照。编辑/归档库中的资源不回溯更改已有记录。新聊天室使用最新资料；归档内容不再进入新选择，恢复后可再次使用。暂不提供永久删除家庭资源。

## 三个独立开发开关

| 环境配置 | 默认 | 控制 |
| --- | --- | --- |
| CARDTALK_PROFILE_MANAGEMENT_ENABLED | false | 使用人建档与编辑，以及向扩写提供相关个人背景 |
| CARDTALK_SCENARIO_MANAGEMENT_ENABLED | false | 自定义场景管理，以及向扩写提供自定义场景背景 |
| CARDTALK_CUSTOM_CARDS_ENABLED | true | 自定义卡片管理及其 AI 扩写 |

在本机环境文件配置后重启 `npm run dev:backend`；进入家庭管理会重新检查状态。当前 Mac 已开启三项供开发体验。关闭模块时现有资料可只读查看；原始表达与历史保留。资料/场景背景未开启时客户端不发送对应高级上下文；自定义卡片扩写被关闭时保留原始表达并说明限制，不丢弃选卡或伪造候选。后端也在调用模型和扣额前独立验证开关。

这些是单进程开发配置，匿名体验身份不构成真实家庭身份，也没有支付、成员权限和正式授权期限。微信小程序继续为轻量本机体验，不开放高级管理入口。不能将此机制用于公网付费授权。

## 资料与 AI 的边界

发送给扩写服务的是所选卡片的 ID/文字/含义，选定场景的必要描述，以及当次使用人的姓名、年龄、语言、兴趣、性格、表达习惯与单独填写的当前状态。照片、家人观察、观察记录人、其他使用人资料和历史正文均不发送。

兴趣、性格和场景只是背景，不能用来确定本人当前意图。情绪语气仍依据明确情绪卡；自定义否定卡也会抑制肯定情绪。本人可拒绝、编辑或使用原始表达，AI 不自动发声。

卡片编辑器中的试听始终使用设备声音，未保存文字不发送给讯飞或模型。沟通中的正式朗读遵守语音设置；原始选卡含自定义内容时，Web 的「播放原始卡片」会用设备朗读全部原始文字，避免寻找不存在的固定音频。其他端没有对应预置音频时说明替代方式，不能静默跳过该卡。

## 保存与图片

- 使用人最多 50 位、自定义卡片 200 张、场景 50 个，包含归档资源。
- 图片仅允许本机 PNG/JPEG/WebP，不接受 SVG 或远端链接；单张不超过 200 KiB，宽高不超过 1024 像素；家庭图片总量不超过 2 MiB。
- 数据沿用本机 v1 存储键，旧记录迁移时补空家庭库，保留原有沟通记录和开关。
- 图片随选卡形成快照，重复表达会占用更多空间。沿用已有 5 MiB JSON 字符上限；领域变更超额时拒绝且保留原状态，平台存储也可能更早失败。
- 管理表单先完成实际本机写入，成功后才显示已保存；写入失败保留输入、显示错误并可重试。损坏原始记录继续保留和保护，不被管理表单覆盖。
- 设置中的备份包含家庭资料、照片和沟通内容。清理浏览器/微信数据会移除本机资料；目前没有云端恢复或备份导入。

## 验证

新增浏览器回归覆盖建档/场景/卡片至沟通、扩写背景与隐私、编辑后旧快照、归档恢复、三个独立开关、真实 PNG 与无说明卡、拒绝错误图片、存储写入失败、设备试听和 390px 布局。供应商响应均为明确测试替身；本机开发开关另作真实服务冒烟检查。

后端覆盖各开关独立拒绝、上下文边界与不落盘、额度/去重兼容，以及 20 张 50 字卡片的 1019 字原始表达完整透传语音接口。语音上限现为 1100 UTF-16 单位，超限明确拒绝；不截断本人表达。

当前没有真实 DeepSeek/讯飞效果、微信开发者工具或移动真机验证。H5 家庭管理不代表完整 P2 交付；成员权限、个人声音与输入适配、正式付费授权和云数据仍按产品全景后续实现。
