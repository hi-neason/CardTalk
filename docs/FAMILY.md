# 家庭管理、权限与数据边界

日期：2026-10-12。覆盖本机家庭管理、正式家庭身份和独立权益、显式跨设备同步及数据生命周期；移动端已接入管理流程，但尚待原生编译和真机验收。

## 使用流程

1. Web 顶栏进入「家庭管理」，创建使用人、卡片和场景。
2. 使用人可上传、预览、替换或移除照片，并填写年龄、语言、兴趣、性格与表达习惯；家人观察记录有独立来源和日期。
3. 自定义卡片可以是词语或整句，选择分类、内置图案或本机图片，并关联场景。
4. 场景可上传、预览、替换或移除图片，说明环境、常见活动和物品，选取推荐卡片；通用词汇始终可选。
5. 创建聊天室选择使用人和场景，单独填写当次状态。选卡后扩写、确认、朗读和反馈延续原沟通流程。
6. 本机历史按使用人档案、预设、场景和文字查看；档案与资源可归档、恢复。

当前会话及历史使用创建时的资料和选卡快照。编辑/归档库中的资源不回溯更改已有记录。新聊天室使用最新资料；归档内容不再进入新选择，恢复后可再次使用。本机数据管理另提供按使用人永久删除及全量清除，需预览并明确确认；这些操作与资源归档、服务端删除申请分别处理。

## 三个独立开发开关

| 环境配置 | 默认 | 控制 |
| --- | --- | --- |
| CARDTALK_PROFILE_MANAGEMENT_ENABLED | false | 使用人建档与编辑，以及向扩写提供相关个人背景 |
| CARDTALK_SCENARIO_MANAGEMENT_ENABLED | false | 自定义场景管理，以及向扩写提供自定义场景背景 |
| CARDTALK_CUSTOM_CARDS_ENABLED | true | 自定义卡片管理及其 AI 扩写 |

在本机环境文件配置后重启 `npm run dev:backend`；进入家庭管理会重新检查状态。这些配置仅控制未选择正式家庭的本机体验。关闭模块时现有资料可只读查看；原始表达与历史保留。资料/场景背景未开启时客户端不发送对应高级上下文；自定义卡片扩写被关闭时保留原始表达并说明限制，不丢弃选卡或伪造候选。后端也在调用模型和扣额前独立验证开关。

匿名体验身份不构成正式家庭身份。正式账户支持注册、登录、家庭创建、一次性邀请、成员角色和逐使用人访问范围；明确选择「使用这个家庭的功能」后，以服务端角色和家庭独立权益为准，不叠加开发开关。Web 使用 HttpOnly Cookie，原生使用只留内存的 Bearer，冷启动重新登录；登录不上传本机资料。微信小程序继续为轻量本机体验，不开放高级管理入口。

家庭权益、期限、订单、续期、取消和退款已有持久实现。默认支付 provider 为 none、商品目录为空，价格/期限须配置；真实支付未验收。微信 H5 支付购买入口仅 H5 使用，原生端可查看权益/订单。详见 [商业授权](BILLING.md)。

## 资料与 AI 的边界

发送给扩写服务的是所选卡片的 ID/文字/含义，选定场景的必要描述，以及当次使用人的姓名、年龄、语言、兴趣、性格、表达习惯与单独填写的当前状态。照片、家人观察、观察记录人、其他使用人资料和历史正文均不发送。

兴趣、性格和场景只是背景，不能用来确定本人当前意图。情绪语气仍依据明确情绪卡；自定义否定卡也会抑制肯定情绪。本人可拒绝、编辑或使用原始表达，AI 不自动发声。

卡片编辑器中的试听始终使用设备声音，未保存文字不发送给讯飞或模型。沟通中的正式朗读遵守语音设置；原始选卡含自定义内容时，Web 的「播放原始卡片」会用设备朗读全部原始文字，避免寻找不存在的固定音频。其他端没有对应预置音频时说明替代方式，不能静默跳过该卡。

## 保存与图片

- 使用人最多 50 位、自定义卡片 200 张、场景 50 个，包含归档资源。
- 图片仅允许本机 PNG/JPEG/WebP，不接受 SVG 或远端链接；不设置单张文件大小上限，宽高不超过 1024 像素；使用人、卡片和场景的图片共用 2 MiB 总量上限。
- 数据沿用本机 v1 存储键，旧记录迁移时补空家庭库，保留原有沟通记录和开关。
- 使用人和场景图片随聊天室资料形成快照，卡片图片随选卡形成快照；更换或移除图库图片不会改变旧沟通图片。图片展示于创建选择、当前聊天室和历史，重复表达会占用更多空间。沿用已有 5 MiB JSON 字符上限；领域变更超额时拒绝且保留原状态，平台存储也可能更早失败。
- 管理表单先完成实际本机写入，成功后才显示已保存；写入失败保留输入、显示错误并可重试。损坏原始记录继续保留和保护，不被管理表单覆盖。
- 设置中的备份包含家庭资料、照片和沟通内容。清理浏览器/微信数据会移除本机资料；可另行显式启用家庭云同步并选择上传范围，照片与观察分别授权；登录或购买不会自动同步。设置可选择 JSON 备份、预览数量并确认替换本机数据；不合并，活动沟通期间禁止导入，校验或写入失败保留现状。
