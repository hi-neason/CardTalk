# 交付说明与验证边界

日期：2026-10-12。从 P1 MVP 延伸到产品全景实现；当前实现、已运行验证与外部验收分别记录。最新增量见 [长任务检查点](LONG_TASK.md)。

## 当前能力

- 同一设备创建、刷新恢复、结束聊天室；儿童/成人预设、内置场景与无场景、参与者和操作来源。
- 8 个分类、63 张词卡和 7 张常驻表达卡；搜索、顺序/重复次数、撤销、移除、清空，超过 20 张保留已有选卡并提示。
- DeepSeek 服务端接入；等待、取消、失败重试、版本过期保护，最多 3 个候选。选择、修改后确认、拒绝候选并保留原始选卡，或记录原始表达。
- 设备朗读、固定卡片声音、可选讯飞拟人合成；停止、重播和播放状态。历史详情也提供取消与失败提示。语音不自动播放。
- 每轮保存原始选卡、上下文、收到的候选、确认/修改、播放事件、可选理解反馈和反馈者。本机历史支持预设/场景/称呼/表达搜索与删除、备份导出、损坏数据保护。
- 匿名每日扩写额度与请求去重支持持久化；家庭档案、场景、自定义卡片与分析独立授权。正式家庭身份、成员权限、权益、订单、显式同步、内容运营和支持入口已实现。参见 [家庭管理说明](FAMILY.md)。
- 手机、平板和电脑响应布局；大字设置；H5 按钮键盘操作、实际输入名称、弹窗焦点返回和 Tab 范围。

## AI、声音与情绪设置

三项开关独立保存到本机。旧版 v1 记录补充默认值（扩写开、讯飞/情绪关），不删除历史；错误类型仍保留原始数据并提示。关闭扩写不调用模型，仍可确认原始选卡、使用讯飞或设备发声。开关变化取消等待与播放；扩写/情绪变化使未确认候选失效，历史不被重写。

情绪只从明确的内置情绪卡读取：开心 happy、难过 sad、生气 angry、害怕 fearful。重复同情绪去重，多个不同情绪、否定/拒绝卡使用 neutral；疼痛、饥渴或场景不推断为某种情绪。用户修改候选后朗读默认 neutral。关闭识别不发送额外 emotion 标记，模型仍应保留卡片本身的情绪与否定含义。

讯飞超拟人通过服务端 JDK WebSocket/HMAC-SHA256 调用，合成后返回 MP3。停止通过传输取消与同身份/请求编号的服务端取消共同处理；合成有期限、音频/帧大小上限和完整性检查。

官方协议边界：

- [超拟人合成](https://www.xfyun.cn/doc/spark/super%20smart-tts.html)：默认自然音色，当前参数表没有四情绪控制字段。
- [多风格合成](https://www.xfyun.cn/doc/spark/voiceclone.html)：消费已授权的多风格 `omni_v1` 音色资源，`style` 使用 glad/sad/angry/afraid；中文 `languageID=0`。应用不训练声音或上传录音；服务器目录只管理已有授权资源，个人远端音色选择已通过增量验收，详见 [声音目录](VOICES.md)。
- [鉴权](https://www.xfyun.cn/doc/spark/general_url_authentication.html)：凭据和签名留在后端，不进入客户端。

健康接口的能力标记仅表示配置完整，不能证明账号/音色权限或声音效果已验收。真实效果需要使用用户自己的授权资源测试；缺失配置或非情绪音色收到情绪请求时明确报错。设备发声的中文声音由系统决定，不能保证其一定是机械音色。小程序没有直接系统 TTS 接口，关闭讯飞后使用预置卡片声音与文字，新句子可选择播放原始卡片。

## 选型决策

采用传统 uni-app、Vue 3、TypeScript 和 Vite CLI。Android/iOS 使用 app-plus，HarmonyOS NEXT 使用 app-harmony；已加入原生 UTS 系统语音、音频、图片和文件适配，不迁移 uni-app x。五端资源构建不等同于原生 SDK 编译、签名或真机验收，见 [移动端说明](MOBILE.md)。

后端为 Java 21、Spring Boot 3.5.13；使用 JDK HttpClient 和 Jackson 直接调用 AI/TTS。PostgreSQL、对象存储、正式账户与家庭授权、云同步、持久报告/扩写额度已实现；本机基础开发仍可使用 Java 进程和单实例 JSON 存储。

服务端 JSON 存储只支持单实例。请求成功并保存额度后才返回成功；失败不扣扩写额度。同一输入请求重试复用编号，成功后主动重新生成使用新编号。缓存过期/后端重启时保留完成元数据，避免旧编号再次扣费，可能返回“已完成，请发起新请求”。匿名安装编号可被重置，不能当作正式付费授权或公网防滥用机制。

## 验证证据与未覆盖范围

以下是个人远端音色增量之前的全量检查点；新音色功能的最终结果以 LONG_TASK 为准。

- 后端 155 项测试通过，0 失败、0 错误、0 跳过，包含真实隔离 PostgreSQL；供应商契约使用 loopback HTTP/WebSocket。
- 前端 134 项单元测试通过；浏览器 100 项回归通过，覆盖沟通、管理、分析、备份/删除、正式家庭权益、同步、支持和运营入口。
- TypeScript/Vue 类型检查及 H5、微信、Android、iOS、Harmony 五端资源构建通过。
- 另有 4 项完整 Spring Boot + PostgreSQL HTTP 集成测试通过。缓存 Java 21 镜像以 UID 10001 运行真实服务通过；隔离 pg_dump/pg_restore 与文件资产恢复后，账户登录、家庭 ID 和图片 HTTP 字节校验通过。这不证明完整多阶段镜像或 Caddy/HTTPS 已运行。
- 未调用真实付费 DeepSeek 或讯飞语音；需要用户在本机配置密钥后进行真实供应商验收。
- 未运行微信开发者工具、iOS/Android/HarmonyOS NEXT 真机；构建成功不代表平台上线或真机可访问性达标。H5 也尚未完成全面 WCAG 审核。
- 固定声音为 macOS 系统中文声音生成的开发素材；商业内容包发布前需要确认声音再分发授权，或替换为授权录音/TTS。SVG 为项目内绘制。
- H5 生产资源缓存、断网刷新及双标签安全升级已通过回归；首次离线访问或缓存清除仍不可用。小程序离线依赖平台保留已准备资源。

## 依赖与开发边界

使用 npm 官方 registry 完成依赖审计。编译器通过 scoped override 使用 Vite 5.4.21，测试工具升级至 Vitest 4.1.11 并单独使用 Vite 6.4.3；两者不共用不同主版本的编译链。升级后重新验证类型、测试、H5/微信构建和浏览器流程。

早期 H5/微信依赖检查的 `npm audit` 报告 51 项（该数字不是新增原生依赖后的最新审计）（0 critical、24 high、15 moderate、12 low），包括 DCloud 锁定的 Vue/server-renderer、intlify、图片/压缩工具、PostCSS 和 Vite 5 等依赖。当前无 SSR、测试 UI 或公网开发服务；这些条件不代表已消除告警。未使用 `audit fix --force` 自动更换 DCloud 编译器。正式发布前须按实际产物和调用路径升级工具链、审查依赖并重新验收。

## 发布前剩余验收

产品全景内的账户、家庭、分析、同步、权益、资源运营和支持流程均已有实现。个人远端音色目录及其前端选择已实现并通过增量验证，状态见 LONG_TASK。真实 DeepSeek/讯飞效果、支付商户回调、原生 SDK 编译/签名/真机、微信开发者工具、完整部署镜像与公网 HTTPS 需要对应资源和环境。当前不声称已可商业上线。

本机统计保留事实与 AI 叙述区别，不把播放完成等同于理解成功。JSON 备份需校验、预览、确认替换；云同步另行选择范围；本机永久删除、全量清除和服务端删除申请是不同操作。删除申请得到回复不等于家庭数据已自动删除。
