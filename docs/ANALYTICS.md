# 本机沟通分析与报告

Web 顶栏进入「分析报告」。本阶段提供本机统计与 JSON 报告，不调用模型、不上传历史或照片，不提供诊断或能力评分。

## 开启

在 `backend/.env` 配置 `CARDTALK_ANALYTICS_ENABLED=true`，重启后端。默认关闭，独立于使用人、场景、自定义卡片管理；只开分析也能统计体验者历史。当前 Mac 已开启供开发体验。这是开发开关，不是正式购买授权；微信轻量体验不开放分析入口。

## 统计口径

- 以已确认表达为样本，未确认选卡与草稿不计入；未结束聊天室中已确认的表达计入。
- 使用人和场景以每条表达的历史快照筛选；资料编辑或归档不改变历史归属。
- 日期按本机时区与表达创建时间，包含起止日期整日；无记录日期不补造数据。
- 反馈覆盖率 = 有明确反馈的表达 / 全部样本；理解率 =「理解了」/ 有明确反馈的表达。没有反馈时理解率显示「暂无反馈」。未反馈、播放完成均不代表理解。
- 表达方式区分原始表达、AI候选确认、候选修改后确认；操作来源区分本人、家人协助、未知，不推断本人能力。
- 常用选卡按卡片 ID 统计，同一条表达重复选择只计一次。常用场景和每日表达均按样本数计数。频次不等于本人喜好。

统计依据可进入对应聊天室历史，查看完整表达、选卡、反馈和播放状态。JSON 导出包含筛选条件、生成时间和统计，包含卡片/场景名称，不包含照片或表达正文；它不是可恢复数据的备份。

## 后续全景范围

本阶段未交付 AI 叙述报告、前后时间段比较、家庭云同步、账号权限、真实购买授权、个人声音与完整输入适配，也未代表原生 App 已完成。
