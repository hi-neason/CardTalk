## 产品约束

- 同机面对面聊天室；不擅自新增多人实时聊天室。Android、iOS、鸿蒙手机和平板，电脑 Web，微信本机轻量体验。
- 单句最多20卡，最多3候选，明确确认后发声。保留拒绝、疼痛、停止、否定和选卡来源。反馈、确认、播放是独立事实。
- DeepSeek API 扩写，讯飞授权声音合成；不开发本地模型。密钥仅服务端。Java/JDK/Jackson实现AI，不引入编排框架。
- 微信数据默认本机；开通分析或联网扩写不自动上传历史。云同步显式选择范围。
- 本机档案、图片、观察与历史快照兼容迁移；长期观察不直接代表当前意图。旧数据缺失指标明确记缺失，不推断拒绝率或耗时。
- 使用人、场景、分析独立权益，不捆绑；价格、期限、渠道、退款策略可配置，不自行替用户制定商业政策。
- 不产生虚假付费成功、假成员权限、假真机验收。未配置供应商保持明确错误与基础表达。
- Commit 无 Codex/OpenAI attribution。常规实现与验证自行完成；公网发布、真实支付、破坏性迁移分别遵循实际授权。
